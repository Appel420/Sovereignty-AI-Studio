# AI_Eyes_Medical

Sample medical imaging workflow (dataset → train → evaluate → explainability).

This directory is intentionally *sample-only* and is not imported by the main app or CI tests.

## Usage

```bash
python3 AI_Eyes_Medical/workflow.py --help
```

If you want to run the full workflow, install the optional dependency:

```bash
python3 -m pip install medicalai
```
