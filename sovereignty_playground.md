# Sovereignty Playground

## Overview

The **Sovereignty Playground** is a local AI development environment designed to operate entirely offline. It provides a comprehensive set of tools and features for developers to work with AI models and related functionalities without relying on cloud services.

## Core Features

1. **Local Execution**
   - All developer-facing tools and processes run locally, ensuring no dependency on cloud services.

2. **Offline Tools**
   - Git Repository Explorer
   - Dependency Graph
   - Python, Swift, Rust, and TypeScript Inspectors
   - JSON, YAML, and TOML Validators
   - Markdown Preview and Hex/Binary Inspectors
   - Certificate and PEM Inspectors
   - ML-DSA Verifier and SHA256/SHA3 Verifiers
   - File and Directory Differs
   - Symbol and Dead Code Scanners
   - Import and Build Graphs
   - Local Documentation and Log Search

3. **Process Visibility**
   - Displays running processes with details such as PID, uptime, and resource usage.

4. **Version Control**
   - Documents and projects are versioned and searchable, ensuring no data is overwritten.

5. **Integration**
   - Integrates with existing systems such as AuthorityGate, SCAR, and Vault while preserving the current architecture.

## Key Components

- **Model Registry:** Manages AI models and their configurations.
- **Tool Registry:** Provides a centralized registry for developer tools.
- **Offline Executor:** Handles execution tasks locally.
- **Vault Interface:** Stores and manages documents, projects, policies, and more.
- **Workspace:** Functions like a local VS Code explorer with integrated tools.

## Dashboard Features

- Displays running services, active policies, allowed providers, and related status information.
- Provides detailed insights into resource usage and job execution.

## Integration

The Playground integrates seamlessly with existing execution chains while maintaining the current architecture.

## Usage

Developers can use the Playground to perform tasks such as:

- Code review
- Refactoring
- Dependency analysis
- Security scanning
- Local AI development and model inspection

All of these workflows are designed to run within the local environment.

## Additional Notes

The environment is designed to be developer-friendly, providing tools and visibility to manage and optimize AI development locally without relying on cloud services.
