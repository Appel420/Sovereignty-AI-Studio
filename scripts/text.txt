    <section id="sec-chemistry">
      <div class="section-hdr">
        <div class="section-num">§01</div>
        <div class="section-title">Molecular Chemistry of DNA</div>
        <div class="section-sub">Nucleotide structure · Base-pairing thermodynamics · Backbone geometry</div>
      </div>

      <div class="info-block" data-label="Nucleotide Components">
        <p>Each DNA nucleotide is composed of three covalently bonded components: a <strong>deoxyribose sugar</strong> (C5H10O3), a <strong>phosphate group</strong> (PO₄³⁻), and one of four <strong>nitrogenous bases</strong>. The phosphodiester backbone runs antiparallel: one strand 5'→3', the complementary strand 3'→5'.</p>
        <p>Purines (A, G): two-ring structures. Pyrimidines (C, T): single-ring structures. Watson-Crick base-pairing: <em>A=T</em> (2 hydrogen bonds, ΔG ≈ −1.0 kcal/mol) · <em>G≡C</em> (3 hydrogen bonds, ΔG ≈ −1.5 kcal/mol).</p>
      </div>

      <h3 class="subsec">Base-Pairing Thermodynamics</h3>
      <div class="eq-block">Tm = 81.5 + 16.6·log[Na⁺] + 0.41·(%GC) − 675/L
ΔG°(AT) = −1.0 kcal/mol · ΔG°(GC) = −1.5 kcal/mol
ΔG°(duplex) = ΔH° − T·ΔS°  (nearest-neighbor model)
[Na⁺] standard: 50 mM · L = length in bp</div>

    <!-- §03 MATHEMATICAL DECODING -->
    <section id="sec-math" style="margin-top:40px">
      <div class="section-hdr">
        <div class="section-num">§03</div>
        <div class="section-title">Mathematical Decoding Framework</div>
        <div class="section-sub">Information theory · PWM scoring · Kozak scoring · CAI</div>
      </div>
      <div class="info-block" data-label="Information Theory">
        <p><strong>Shannon Entropy:</strong> H = −∑ pᵢ·log₂(pᵢ) bits/nucleotide. Maximum H = 2.0 bits for uniform ATGC. Regulatory elements compress entropy (high conservation → low H). CpG islands: GC-rich, H → 1.0–1.4 bits.</p>
        <p><strong>Position Weight Matrix (PWM) Score:</strong> S = ∑ₚ log₂[f(b,p) / p(b)] where f(b,p) = observed frequency of base b at position p, p(b) = background frequency. Threshold ≥ 80% of max PWM score for binding-site calls.</p>
      </div>
      <div class="eq-block">Shannon H:      H = -Σᵢ pᵢ log₂(pᵢ)    [bits/nt]
H_max = 2.0000 bits  (uniform ATGC)
Redundancy R:   R = (1 - H/H_max) × 100%

PWM Score:      S = Σₚ log₂[ f(b,p) / p(b) ]
Kozak Score:    K = w(−3)·A/G + w(+4)·G     (positions rel. ATG)
CAI:            CAI = exp[ (1/L) Σᵢ ln w(cᵢ) ]  w = RSCU ratio</div>

      <h3 class="subsec">Empirical Thresholds</h3>
      <table class="bio-table">
        <thead><tr><th>Feature</th><th>H (bits)</th><th>GC%</th><th>Interpretation</th></tr></thead>
        <tbody>
          <tr><td>CpG Island</td><td>1.0–1.4</td><td>≥55%</td><td>Promoter, regulatory. CpG Obs/Exp ≥ 0.6</td></tr>
          <tr><td>Coding Exon</td><td>1.7–1.95</td><td>50–65%</td><td>High complexity, codon usage bias</td></tr>
          <tr><td>Enhancer</td><td>1.5–1.9</td><td>40–60%</td><td>TF binding, moderate complexity</td></tr>
          <tr><td>Simple Repeat</td><td>&lt;0.5</td><td>Variable</td><td>Low complexity, high redundancy</td></tr>
          <tr><td>LINE/SINE</td><td>1.6–1.85</td><td>35–45%</td><td>AT-rich, moderate entropy</td></tr>
        </tbody>
      </table>

    <section id="sec-workflow" style="margin-top:40px">
      <div class="section-hdr">
        <div class="section-num">§06</div>
        <div class="section-title">Multi-Layer Decoding Workflow</div>
        <div class="section-sub">Decode → Diagnose → Intervene → Validate</div>
      </div>
      <div class="info-block" data-label="Six-Layer Pipeline">
        <p><strong>Layer 1 — Raw sequence → ORF identification:</strong> Multi-frame translation, Kozak scoring, comparative genomics (PhyloP/PhastCons), Ribo-seq confirmation.</p>
        <p><strong>Layer 2 — Regulatory motif detection:</strong> PWM scanning (JASPAR 2024), delta-PWM scoring for variant effects, combinatorial TF binding syntax (syntax grammar rules).</p>
        <p><strong>Layer 3 — Epigenetic overlay:</strong> Full 15-state ChromHMM integration per cell type, CUT&amp;RUN signal, DNA methylation (EM-seq), ATAC-seq accessibility.</p>
        <p><strong>Layer 4 — 3D chromatin architecture:</strong> Hi-C TAD boundaries, A/B compartment calls, Activity-by-Contact (ABC) enhancer-gene mapping score ≥ 0.02.</p>
        <p><strong>Layer 5 — Variant-to-function:</strong> Allele-specific ATAC-seq, MPRA, CRISPRi perturbation, ClinVar variant effect prediction.</p>
        <p><strong>Layer 6 — Functional simulation:</strong> Cell-type-specific in silico validation before wet-lab commitment.</p>
      </div>
    </section>

    <!-- §07 PROTOCOL -->
    <section id="sec-protocol" style="margin-top:40px">
      <div class="section-hdr">
        <div class="section-num">§07</div>
        <div class="section-title">Step-by-Step Decoding Protocol</div>
        <div class="section-sub">Operational sequence for regulatory variant interpretation</div>
      </div>
      <div class="info-block" data-label="Protocol Steps">
        <p><strong>Step 1 — Disambiguate protein-coding signal:</strong> Kozak scoring at ATG candidates. CAI (Codon Adaptation Index) ≥ 0.7 for bona fide ORFs. Comparative genomics: PhyloP conservation ≥ 2.0 at synonymous positions. Ribo-seq read density at candidate ORF ≥ 5× background.</p>
        <p><strong>Step 2 — Parse regulatory grammar:</strong> PWM motif scanning with JASPAR CORE 2024 vertebrate TF models (≥756 models). Delta-PWM score for variant: ΔS = S(ref) − S(alt). |ΔS| ≥ 2.0 bits = significant binding disruption.</p>
        <p><strong>Step 3 — Read chromatin state machine:</strong> Map each regulatory element to 15-state ChromHMM in the relevant cell type. State E1/E2 = active; E5 = Polycomb-repressed (reversible); E6 = constitutive heterochromatin (hard to reverse).</p>
        <p><strong>Step 4 — Decode 3D architecture:</strong> Is the candidate enhancer in the same TAD as the target gene? Activity-by-Contact score ≥ 0.02 required for causal enhancer-gene linkage call.</p>
        <p><strong>Step 5 — Integrate variant-to-function:</strong> Prioritize variants in open chromatin (ATAC-seq) + high PWM-score positions + E1/E2 chromatin state.</p>
      </div>
    </section>

    if(!canvas) return { toggle:()=>{} };
    const ctx = canvas.getContext('2d');
    let t=0, running=true, raf=null, lastTs=0;
    const FPS=30, INTERVAL=1000/FPS;
    function resize(){ canvas.width=canvas.offsetWidth; canvas.height=canvas.offsetHeight; }
    resize();
    window.addEventListener('resize', resize, {passive:true});
    function draw(ts){
      if(!running){ raf=null; return; }
      raf=requestAnimationFrame(draw);
      if(ts-lastTs<INTERVAL) return;
      lastTs=ts;
      ctx.clearRect(0,0,canvas.width,canvas.height);
      const cx=canvas.width/2, pairs=38, step=canvas.height/pairs, amp=canvas.width*0.30;
      for(let i=0;i<pairs;i++){
        const y=i*step, ang=(i/pairs)*Math.PI*6+t;
        const x1=cx+Math.sin(ang)*amp, x2=cx+Math.sin(ang+Math.PI)*amp;
        const z1=(Math.cos(ang)+1)*0.5, z2=(Math.cos(ang+Math.PI)+1)*0.5;
        const nts=['A','T','G','C'], nt1=nts[i%4], nt2=nts[(i+2)%4];
        if(Math.abs(x1-x2)>3){
          const g=ctx.createLinearGradient(x1,y,x2,y);
          g.addColorStop(0,NT_CLR[nt1]+'30'); g.addColorStop(1,NT_CLR[nt2]+'30');
          ctx.beginPath(); ctx.moveTo(x1,y); ctx.lineTo(x2,y);
          ctx.strokeStyle=g; ctx.lineWidth=1; ctx.stroke();
        }
        [[x1,z1,nt1],[x2,z2,nt2]].forEach(([x,z,nt])=>{
          const r=2.5+z*4.5, alpha=Math.floor(50+z*185).toString(16).padStart(2,'0');
          ctx.beginPath(); ctx.arc(x,y,r,0,Math.PI*2);
          ctx.fillStyle=NT_CLR[nt]+alpha; ctx.fill();
        });
      }
      [0,Math.PI].forEach((offset,idx)=>{
        ctx.beginPath();
        for(let i=0;i<=pairs;i++){
          const y=i*step, x=cx+Math.sin((i/pairs)*Math.PI*6+t+offset)*amp;
          i===0?ctx.moveTo(x,y):ctx.lineTo(x,y);
        }
        ctx.strokeStyle=idx===0?'rgba(0,200,240,0.22)':'rgba(0,232,122,0.18)';
        ctx.lineWidth=1.8; ctx.stroke();
      });
      t+=0.007;
    }
    document.addEventListener('visibilitychange',()=>{
      if(document.hidden){running=false;if(raf){cancelAnimationFrame(raf);raf=null;}}
      else if(running){raf=requestAnimationFrame(draw);}
    });
    function toggle(){
      running=!running;
      const btn=$id('canvasToggle');
      btn.textContent=running?'Pause Animation':'Resume Animation';
      btn.setAttribute('aria-pressed',String(running));
      if(running) raf=requestAnimationFrame(draw);
    }
    raf=requestAnimationFrame(draw);
    return { toggle };
  })();

  function seqAnalyze(){

  /* ── TOOL 2: ENTROPY CALCULATOR ── */
  function calcEntropy(){
    const raw=cleanDNA($id('entIn').value);
    if(raw.length<2){
      $id('hV').innerHTML='--<span class="e-unit">bits</span>';
      $id('rV').innerHTML='--<span class="e-unit">%</span>';
      $id('entOut').textContent='Awaiting input (min 2 nucleotides)...';
      return;
    }
    const ct={A:0,T:0,G:0,C:0};
    raw.split('').forEach(n=>{ if(ct[n]!==undefined) ct[n]++; });
    const tot=raw.length;
    let H=0; const det=[];
    ['A','T','G','C'].forEach(nt=>{
      if(ct[nt]>0){
        const p=ct[nt]/tot;
        H-=p*Math.log2(p);
        det.push(`  p(${nt}) = ${(p*100).toFixed(1).padStart(5)}%   contribution = ${(p*Math.log2(p)*-1).toFixed(4)} bits`);
      }
    });
    const Hmax=2.0, R=(1-H/Hmax)*100;
    const interp=H>1.9?'Near-random — high sequence complexity':H>1.5?'Moderate complexity':H>1.0?'Low complexity — compositional bias':'High redundancy — likely simple repeat or homopolymer';
    $id('hV').innerHTML=H.toFixed(4)+'<span class="e-unit">bits</span>';
    $id('rV').innerHTML=R.toFixed(1)+'<span class="e-unit">%</span>';
    $id('entOut').textContent=`Length: ${tot} bp\n\nNucleotide contributions:\n${det.join('\n')}\n\nH  = ${H.toFixed(4)} bits/nt\nH_max = ${Hmax.toFixed(4)} bits/nt\nRedundancy R = ${R.toFixed(2)}%\n\n${interp}`;
  }

  /* ── TOOL 3: CODON DECODER ── */
  function decodeCodon(){
    const raw=cleanDNA($id('codIn').value);
    const frame=parseInt($id('frameS').value);
    if(!raw){ ['mrnaO','codonO','protO','protLen'].forEach(id=>$id(id).textContent='--'); return; }
    const mRNA=raw.slice(frame).replace(/T/g,'U');
    $id('mrnaO').innerHTML=colorDNA(mRNA,'RNA');
    const cods=[]; let prot='', sl='';
    for(let i=0;i<mRNA.length-2;i+=3){
      const cod=mRNA.slice(i,i+3);
      if(cod.length<3) break;
      const aa=CODON_TABLE[cod]||'?';
      const isStart=cod==='AUG'&&i===0;
      const c1=isStart?`<span style="color:var(--amber)">${cod}</span>`:
               aa==='Stop'?`<span style="color:var(--red)">${cod}</span>`:
               `<span style="color:var(--cyan)">${cod}</span>`;
      cods.push(`${c1}→<span style="color:var(--green)">${aa}</span>`);
      if(aa==='Stop'){ sl+='*'; break; }
      prot+=aa+'-';
      sl+=SINGLE_LETTER[aa]||'?';
    }
    $id('codonO').innerHTML=cods.join('  ')||'No complete codons';
    $id('protO').textContent=prot.replace(/-$/,'')||'--';
    const aas=sl.replace('*','').length;
    $id('protLen').textContent=aas>0?`${aas} amino acids | One-letter: ${sl}`:'--';
  }

  /* ── TOOL 4: ORF FINDER ── */
  function findORFs(){
    const raw=cleanDNA($id('orfIn').value);
    if(!raw){ $id('orfOut').textContent='No sequence entered.'; return; }
    const STOPS=['TAA','TAG','TGA'];
    const marks=new Array(raw.length).fill('');
    const found=[];
    // Search all 3 forward frames
    for(let frame=0;frame<3;frame++){
      let inOrf=false, oStart=-1;
      for(let i=frame;i<=raw.length-3;i+=3){
        const cod=raw.slice(i,i+3);
        if(cod==='ATG'&&!inOrf){ marks[i]=marks[i+1]=marks[i+2]='s'; inOrf=true; oStart=i; }
        else if(STOPS.includes(cod)&&inOrf){
          marks[i]=marks[i+1]=marks[i+2]='x';
          found.push({f:frame+1,s:oStart,e:i+3,len:i+3-oStart});
          inOrf=false;
        } else if(inOrf){ marks[i]=marks[i+1]=marks[i+2]='b'; }
      }
    }
    const html=raw.split('').map((c,i)=>{
      if(marks[i]==='s') return `<span class="os">${c}</span>`;
      if(marks[i]==='x') return `<span class="ox">${c}</span>`;
      if(marks[i]==='b') return `<span class="ob">${c}</span>`;
      return c;
    }).join('');
    $id('orfOut').innerHTML=html;
    found.sort((a,b)=>b.len-a.len);
    $id('orfList').textContent=found.length
      ? found.map((o,i)=>`ORF ${i+1}: Frame +${o.f}  pos ${o.s+1}–${o.e}  |  ${o.len} bp  |  ${Math.floor(o.len/3)-1} codons  |  ~${Math.floor((o.len/3-1)*110)} Da`).join('\n')
      : 'No complete ORFs found in frames +1/+2/+3. Try a longer sequence.';
  }
  function clearORF(){ $id('orfIn').value=''; $id('orfOut').textContent='Awaiting sequence...'; $id('orfList').textContent='ORF list will appear here.'; }

  /* ── TOOL 5: MOTIF SCANNER ── */
  function scanMotif(){
    const raw=cleanDNA($id('motifSeq').value);
    const sel=$id('motifSel').value;
    if(!raw){ $id('motifResult').textContent='No sequence entered.'; return; }
    let pattern;
    if(sel==='CUSTOM'){
      pattern=cleanDNA($id('motifCustom').value);
      if(!pattern){ $id('motifResult').textContent='Enter a custom motif.'; return; }
    } else if(sel==='EBOX'){
      pattern='EBOX';
    } else {
      pattern=MOTIFS[sel]||sel;
    }
    const hits=[];
    if(pattern==='EBOX'){
      // CA..TG — degenerate
      for(let i=0;i<=raw.length-6;i++){
        if(raw[i]==='C'&&raw[i+1]==='A'&&raw[i+4]==='T'&&raw[i+5]==='G'){
          hits.push({pos:i+1,seq:raw.slice(i,i+6)});
        }
      }
    } else {
      const pLen=pattern.length;
      for(let i=0;i<=raw.length-pLen;i++){
        if(raw.slice(i,i+pLen)===pattern) hits.push({pos:i+1,seq:raw.slice(i,i+pLen)});
      }
    }
    if(!hits.length){
      $id('motifResult').textContent=`No hits found for motif "${sel==='CUSTOM'?pattern:sel}" in ${raw.length} bp sequence.`; return;
    }
    $id('motifResult').innerHTML=`Found ${hits.length} hit${hits.length!==1?'s':''} for <span class="motif-hit">${esc(sel==='CUSTOM'?pattern:sel)}</span> in ${raw.length} bp:\n\n`
      +hits.map(h=>`  Position ${h.pos}: <span class="motif-hit">${esc(h.seq)}</span>  (context: ...${esc(raw.slice(Math.max(0,h.pos-4),h.pos-1))}<span class="motif-hit">${esc(h.seq)}</span>${esc(raw.slice(h.pos-1+h.seq.length,Math.min(raw.length,h.pos-1+h.seq.length+4)))}...)`).join('\n');
  }

  /* ── TOOL 7: REVERSE COMPLEMENT + Tm ── */
  function calcComp(){
    const raw=cleanDNA($id('compIn').value);
    if(!raw){ ['compRC','compRev','compComp','tmBasic','tmWallace','tmSanta','tmNote'].forEach(id=>$id(id).textContent='--'); return; }
    const comp=raw.split('').map(n=>COMP[n]||n).join('');
    const rc=comp.split('').reverse().join('');
    const rev=raw.split('').reverse().join('');
    $id('compRC').innerHTML=colorDNA(rc);
    $id('compRev').innerHTML=colorDNA(rev);
    $id('compComp').innerHTML=colorDNA(comp);
    const L=raw.length;
    const gcC=raw.split('').filter(c=>c==='G'||c==='C').length;
    const atC=L-gcC;
    const na=parseFloat($id('naConc').value)||50;
    // Wallace rule: 2*AT + 4*GC (for oligos < 20 bp)
    const tmWallace=2*atC+4*gcC;
    // Basic formula: 81.5 + 16.6*log10[Na+/1000] + 0.41*GC% - 675/L
    const tmBasic=81.5+16.6*Math.log10(na/1000)+0.41*(gcC/L*100)-675/L;
    // SantaLucia nearest-neighbor approximation
    let dH=0, dS=-5.69; // initiation
    for(let i=0;i<L-1;i++){
      const pair=raw[i]+raw[i+1];
      if(NN[pair]){ dH+=NN[pair].H; dS+=NN[pair].S; }
    }
    const R=1.987; // cal/mol·K
    const tmSanta=(dH*1000/(dS+R*Math.log(1/(4e-6))))-273.15+16.6*Math.log10(na/1000);
    $id('tmBasic').innerHTML=(L<8?'N/A':tmBasic.toFixed(1))+'<span class="e-unit">°C</span>';
    $id('tmWallace').innerHTML=tmWallace.toFixed(1)+'<span class="e-unit">°C</span>';
    $id('tmSanta').innerHTML=(L<4?'N/A':tmSanta.toFixed(1))+'<span class="e-unit">°C</span>';
    const note=L<14?'Wallace rule most accurate for short oligos (<14 bp).\nSantaLucia rule recommended for ≥14 bp.':'SantaLucia nearest-neighbor model recommended for accurate Tm prediction.\nAssumes [Na⁺] = '+na+' mM, [oligo] = 4 µM.';
    $id('tmNote').textContent=`${L} bp · GC: ${gcC} (${(gcC/L*100).toFixed(1)}%) · AT: ${atC}\n${note}`;
  }

  function persist(){ localStorage.setItem(STORAGE,JSON.stringify(state)); }
  function isChecked(id){ return !!state[id]; }
  function toggle(id){ state[id]=!state[id]; persist(); updateAll(); }
  function expand(id){
    const item=$id('or-item-'+id);
    if(!item) return;
    item.classList.toggle('expanded');
    const btn=$id('or-exp-'+id);
    if(btn) btn.textContent=item.classList.contains('expanded')?'▲':'▼';
  }

  function allTaskIds(){ return PHASES.flatMap(p=>p.groups.flatMap(g=>g.tasks.map(t=>t.id))); }
  function phaseTaskIds(ph){ return ph.groups.flatMap(g=>g.tasks.map(t=>t.id)); }
  function doneCount(ids){ return ids.filter(id=>!!state[id]).length; }

  function updateAll(){
    const all=allTaskIds(), total=all.length, done=doneCount(all);
    const pct=total>0?Math.round(done/total*100):0;
    $id('or-masterFill').style.width=pct+'%';
    $id('or-masterPct').textContent=pct+'%';
    $id('or-masterCounts').textContent=`${done} / ${total} tasks`;
    PHASES.forEach(ph=>{
      const ids=phaseTaskIds(ph), tot=ids.length, dn=doneCount(ids), pp=tot>0?Math.round(dn/tot*100):0;
      const fill=$id('or-phase-fill-'+ph.id), pctEl=$id('or-phase-pct-'+ph.id);
      const doneEl=$id('or-phase-done-'+ph.id), sbPct=$id('or-sb-pct-'+ph.id);
      if(fill) fill.style.width=pp+'%';
      if(pctEl) pctEl.textContent=pp+'%';
      if(doneEl) doneEl.textContent=`${dn}/${tot}`;
      if(sbPct) sbPct.textContent=pp+'%';
      ids.forEach(id=>{
        const item=$id('or-item-'+id);
        if(item){ if(state[id]) item.classList.add('done'); else item.classList.remove('done'); }
      });
    });
  }

  function render(){
    const sb=$id('orSidebarNav'); if(!sb) return;
    sb.innerHTML='';
    PHASES.forEach(ph=>{
      const ids=phaseTaskIds(ph), tot=ids.length, dn=doneCount(ids);
      const a=document.createElement('a');
      a.className='sb-phase-link'; a.href='#or-phase-'+ph.id;
      a.innerHTML=`<span class="sb-phase-dot" style="background:${ph.color}30;border-color:${ph.color}"></span><span style="flex:1">${ph.num}</span><span class="sb-phase-pct" id="or-sb-pct-${ph.id}">${tot>0?Math.round(dn/tot*100):0}%</span>`;
      sb.appendChild(a);
    });

    const content=$id('orContent'); if(!content) return;
    content.innerHTML=`
      <div class="cl-intro">
        <p>Six-phase organ repair roadmap from <strong>Target Identification</strong> through <strong>Clinical Translation</strong>. Each phase has pass/fail gate criteria. Phases must be completed sequentially. Critical tasks (<span style="color:var(--red);font-family:var(--f-mono);font-size:10px">CRITICAL</span>) must pass before advancing. Sovereign implementation requirements apply from Phase 5 onward.</p>
      </div>
    `;
    PHASES.forEach(ph=>{
      const ids=phaseTaskIds(ph), tot=ids.length, dn=doneCount(ids), pp=tot>0?Math.round(dn/tot*100):0;
      const div=document.createElement('div');
      div.className='phase'; div.id='or-phase-'+ph.id;
      let html=`
        <div class="phase-header">
          <div class="phase-num" style="border-color:${ph.color};color:${ph.color}">${ph.num}</div>
          <div class="phase-title">${ph.title}</div>
          <div class="phase-timeline">${ph.timeline}</div>
        </div>
        <div class="phase-meta"><span>Effort: ${ph.effort}</span></div>
        <div class="phase-gate" style="border-left-color:${ph.color};color:${ph.color}">${ph.gate}</div>
        <div class="phase-progress">
          <div class="phase-bar"><div class="phase-fill" id="or-phase-fill-${ph.id}" style="width:${pp}%;background:${ph.color}"></div></div>
          <div class="phase-pct" id="or-phase-pct-${ph.id}" style="color:${ph.color}">${pp}%</div>
          <div class="phase-done" id="or-phase-done-${ph.id}">${dn}/${tot}</div>
        </div>
      `;
      ph.groups.forEach(g=>{
        html+=`<div class="task-group"><div class="group-title">${g.title}</div>`;
        g.tasks.forEach(t=>{
          const done=!!state[t.id];
          const tagHtml=t.tags.map(tag=>`<span class="ttag ${tag}">${tag}</span>`).join('');
          html+=`
            <div class="task-item${done?' done':''}" id="or-item-${t.id}">
              <div class="task-cb" role="checkbox" aria-checked="${done}" onclick="OR.toggle('${t.id}')" tabindex="0" onkeydown="if(event.key==='Enter'||event.key===' '){OR.toggle('${t.id}')}"><div class="task-check"></div></div>

                <div class="task-tags">${tagHtml}</div>
                <div class="task-detail" id="or-detail-${t.id}">${esc(t.detail)}</div>
              </div>
              <button class="expand-btn" id="or-exp-${t.id}" onclick="OR.expand('${t.id}')" aria-label="Show detail">▼</button>
            </div>
          `;
        });
        html+='</div>';
      });
      div.innerHTML=html;
      content.appendChild(div);
    });
  }

  function resetAll(){ if(!confirm('Reset ALL organ repair progress? This cannot be undone.')) return; state={}; persist(); updateAll(); }
  function exportProgress(){
    const out={exported:stamp(),phases:PHASES.map(ph=>({id:ph.id,title:ph.title,tasks:phaseTaskIds(ph).map(id=>({id,done:!!state[id]}))}))}; 
    const blob=new Blob([JSON.stringify(out,null,2)],{type:'application/json'});
    const a=document.createElement('a'); a.href=URL.createObjectURL(blob); a.download=`organ-repair-progress-${Date.now()}.json`; a.click();
  }

  return { toggle, expand, resetAll, exportProgress };
