4. SIEM Export Procedure

4.1 — Export Command

# Step 1 — Archive logs and generate SHA256 manifest
tar -czf audit.tar.gz logs/ && sha256sum audit.tar.gz > MANIFEST.sha256

# Step 2 — Verify integrity before transmission or retention
sha256sum -c MANIFEST.sha256

4.2 — Output Artifacts

audit.tar.gz MANIFEST.sha256 CSA_STAR_export.json
Retention Requirement
Retain all export artifacts per applicable framework retention schedules. FedRAMP High requires 3 years minimum. DoD IL6 classification handling applies to all archived bundles.
