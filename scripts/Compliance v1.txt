## AGIP Architecture Contract v1.0

This is the right freeze point.

**Core invariant**  
No registry state exists without verifiable evidence.

**Canonical flow**  
External world → Collector → Evidence object → Verification → Canonical registry → Timeline event → Dashboard projection

**Responsibilities**
- **Collectors:** acquire external information only; no registry writes, no trust calculation, no approval logic
- **Evidence fabric:** canonical serialization, hashing, provenance, confidence, verification state, signatures
- **Registry:** stores accepted facts only; does not discover facts
- **Timeline:** event generation, ordering, history, relationships
- **Dashboard:** presentation only; no business logic

**API boundary**
The API should expose verified projections, evidence chains, timeline, and integrity metrics — never “trust me” data.

**Additional invariant**
Every displayed metric must resolve to:
metric → evidence ID → source → timestamp → verification

If any link breaks, the value is unverified.

**Quality gate for AGIP Core v0.1**
- registry mutation requires evidence
- evidence hashes verified
- timeline references evidence
- dashboard only reads projections
- collectors cannot write truth
- tests enforce invariants

This is now a defensible enterprise architecture. Next artifact should be the **schemas**.

Schemas must separate raw observations from trusted registry objects.
Every canonical object must point to evidence.
Validation should fail fast at the boundary, before anything is registered.

```python
from dataclasses import dataclass
from typing import List

@dataclass
class Evidence:
    id: str
    source_id: str
    verification_status: str

@dataclass
class Model:
    model_id: str
    name: str
    evidence_refs: List[str]

class Registry:
    def create_model(self, model: Model, evidence_store: dict) -> None:
        # TODO: reject if no evidence_refs
        # TODO: reject if any ref missing from evidence_store
        # TODO: reject if evidence is not verified
        pass
```

## STEP-BY-STEP SOLUTION
1. Define a shared base schema for `id`, `timestamp`, `source_id`, `evidence_refs`.
2. Add JSON Schema constraints for required fields, formats, and enum values.
3. Enforce invariant: registry writes require at least one valid evidence reference.
4. Enforce collector boundary: collectors output `EvidenceCandidate`, never registry objects.
5. Add pipeline stages: observed → collected → evidence → verified → registered → projected.

class Registry:

    def __init__(self):
        self.models = {}

    def create_model(
        self,
        model: Model,
        evidence_store: dict[str, Evidence]
    ) -> None:

        # Invariant 1:
        # Every registry object requires evidence
        if not model.evidence_refs:
            raise ValueError(
                "Registry rejection: model requires evidence_refs"
            )

        # Invariant 2:
        # Every evidence reference must exist
        missing = [
            ref
            for ref in model.evidence_refs
            if ref not in evidence_store
        ]

        if missing:
            raise ValueError(
                f"Registry rejection: missing evidence {missing}"
            )

        # Invariant 3:
        # Evidence must be verified
        invalid = [
            ref
            for ref in model.evidence_refs
            if evidence_store[ref].verification_status != "verified"
        ]

        if invalid:
            raise ValueError(
                f"Registry rejection: unverified evidence {invalid}"
            )

        # Invariant 4:
        # Register only after validation succeeds
        self.models[model.model_id] = model

from datetime import datetime, timezone

from agip_core.domain.evidence import Evidence


class VerificationError(Exception):
    """Raised when evidence fails admission checks."""
    pass


class Verifier:
    """
    Evidence admission gate.

    Only verified, well-formed evidence
    can proceed to registry admission.
    """

    def __init__(
        self,
        minimum_confidence: float = 0.80
    ):
        self.minimum_confidence = minimum_confidence


    def verify(
        self,
        evidence: Evidence
    ) -> Evidence:
        """
        Validate and normalize evidence.

        Returns:
            Verified Evidence object

        Raises:
            VerificationError
        """

        # 1. Validate timestamp

        try:
            timestamp = evidence.timestamp

            if isinstance(timestamp, str):
                timestamp = datetime.fromisoformat(
                    timestamp.replace(
                        "Z",
                        "+00:00"
                    )
                )

            if timestamp.tzinfo is None:
                raise VerificationError(
                    "Timestamp must include timezone"
                )

        except Exception as exc:
            raise VerificationError(
                f"Invalid timestamp: {exc}"
            )


        # 2. Require verified status

        if evidence.verification_status != "verified":

            raise VerificationError(
                "Evidence status must be verified"
            )


        # 3. Enforce confidence threshold

        if evidence.confidence < self.minimum_confidence:

            raise VerificationError(
                (
                    "Evidence confidence below threshold: "
                    f"{evidence.confidence}"
                )
            )


        # 4. Normalize output

        normalized = evidence.model_copy(
            update={
                "timestamp": timestamp.astimezone(
                    timezone.utc
                )
            }
        )

        return normalized

from agip_core.domain.model import Model
from agip_core.domain.evidence import Evidence
from agip_core.core.evidence.verifier import Verifier


class RegistrationError(Exception):
    """Raised when registry admission fails."""
    pass


class RegistrationPipeline:

    def __init__(
        self,
        verifier: Verifier,
        registry
    ):
        self.verifier = verifier
        self.registry = registry


    def register_model(
        self,
        model: Model,
        evidence_store: dict[str, Evidence]
    ) -> None:
        """
        Admit a model into canonical registry state.

        Only verified evidence can authorize registration.
        """

        # 1. Evidence references required

        if not model.evidence_refs:
            raise RegistrationError(
                "Model requires evidence_refs"
            )


        verified_evidence = {}


        # 2. Resolve evidence references

        for evidence_id in model.evidence_refs:

            evidence = evidence_store.get(
                evidence_id
            )

            if evidence is None:
                raise RegistrationError(
                    f"Missing evidence: {evidence_id}"
                )


            # 3. Re-verify at admission boundary

            verified = self.verifier.verify(
                evidence
            )


            verified_evidence[
                evidence_id
            ] = verified


        # 4. Registry receives only validated state

        self.registry.create_model(
            model=model,
            evidence_store=verified_evidence
        )

import json
from pathlib import Path
import sys


POLICY = Path(
    "AGIP_POLICY.json"
)


REQUIRED_KEYS = [
    "agip_contract_tests",
    "fail_build_on_contract_failure",
    "real_modules_only",
    "required_invariants"
]


REQUIRED_INVARIANTS = {
    "registry_requires_evidence",
    "evidence_must_be_verified",
    "collector_cannot_write_registry"
}


def main():

    if not POLICY.exists():
        print(
            "Missing AGIP_POLICY.json"
        )
        return 1


    data = json.loads(
        POLICY.read_text()
    )


    for key in REQUIRED_KEYS:

        if key not in data:
            print(
                f"Missing policy key: {key}"
            )
            return 1


    invariants = set(
        data["required_invariants"]
    )


    missing = (
        REQUIRED_INVARIANTS
        -
        invariants
    )


    if missing:
        print(
            "Missing invariants:",
            missing
        )
        return 1


    if not data["real_modules_only"]:
        print(
            "Mock governance testing disabled"
        )
        return 1


    print(
        "AGIP policy verified"
    )

    return 0


if __name__ == "__main__":
    sys.exit(main())
